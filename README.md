# shiplog

Bitácora personal para anotar, cada semana, los avances de tus proyectos.

Versión básica: todo corre en el navegador y los datos se guardan en `localStorage` (sin backend ni cuentas).

## Uso

```bash
npm install
npm run dev
```

Abre http://localhost:3000, elige la semana, agrega avances por proyecto y usa "Copiar resumen" para obtener el markdown de la semana.
